## Dedup & change detection
- Hash each collected document; store in `.state/manifest.json` with tier tag.
- **Canon:** changed hash → flag for re-distillation (library update).
- **Inbox:** hashes are for dedup only — episodic sources never change after
  the event; a re-run of ANALYSIS is triggered by spec changes, not new hashes.
- Record every item with source URL/path + `collected_on` for provenance.

## Failure handling
- On fetch failure: retry {{N}} times, then log to progress.md run log and continue.
- Never let one bad source abort the whole run.
- **Inbox events are time-critical:** a missed event window is logged as a
  failure even if the fetch later succeeds.
